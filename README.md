# 아이디어 발굴 프롬프트 워크북

「생성형 AI 도구 활용을 통한 아이디어 발굴법」(AI Build-up 창업 캠프 · AI 창업 아이디어 해커톤) 실습용 웹앱입니다.
문제 정의 → 아이디어 도출 → 비즈니스 모델 단계의 프롬프트 9개와 만능 틀을 담았습니다.
빈칸을 채운 뒤 복사해서 ChatGPT · Gemini · Claude에 바로 붙여 넣을 수 있습니다.

## 기능
- **노란 빈칸**: 눌러서 바로 입력합니다. 자주 쓰는 값은 버튼(칩)으로 고를 수 있습니다.
- **트랙 프리셋**: 트랙 A 「동네 밥상 잇기」, 트랙 B 「나를 알리는 30초 영상」을 누르면 빈칸이 채워집니다.
- **샘플 답 (실습 시뮬레이션)**: 프롬프트 1~9 카드마다 두 트랙을 끝까지 돌린 실제 AI 답을 탭으로 비교합니다 (`samples.js`).
- **PPT 슬라이드 구조**: 카드 위 작은 위치 표시(「1단계 문제 정의 · 프롬프트 1」), 아래 「다음 ›」 줄로 다음 카드로 넘어갑니다.
- **시뮬레이션 조정 반영**: 프롬프트 1 「AI가 먼저 질문하면 한 줄로 답하기」 안내, 프롬프트 2 「네 질문 한 번에 복사」, 마무리에 두 트랙 치명적 약점 나란히.
- **내 결과물 연결**: 문제 정의 문장 · 고른 아이디어 · 한 줄 소개 · 돈의 흐름을 적어 두면 뒤 단계 프롬프트(4·6·7·9)의 빈칸에 자동으로 들어갑니다.
- **복사하고 열기**: ChatGPT·Claude는 프롬프트가 입력된 새 대화로 열리고, Gemini는 복사 후 앱을 엽니다(붙여넣기 필요).
  5·8번처럼 앞 답에 이어서 묻는 프롬프트는 같은 대화창에 붙여 넣도록 안내합니다.
- 문제 정의 문장 공식 빌더, 샘플 답(문제 정의 · 한 줄 아이디어 · 린 캔버스), 결과물 한 번에 복사.
- 입력값은 이 기기 브라우저(localStorage)에만 저장되며 서버로 전송되지 않습니다.

## QR 코드 접속
QR 코드 주소(`?k=접속키`)로 들어온 기기만 워크북을 볼 수 있고, 주소만 입력하면 「QR 코드로 접속해 주세요」 화면이 나옵니다.
한 번 QR로 들어온 기기는 다시 열어도 바로 보이며, 접속키는 주소창에서 바로 지워집니다.
저장소에는 접속키의 해시만 있고, 접속키와 QR 이미지는 강사에게만 따로 전달합니다.
브라우저에서 확인하는 가벼운 잠금이라 보안 장치는 아니므로 개인정보는 넣지 않습니다.

## 실행
빌드 과정이 없는 정적 페이지입니다. `index.html`을 브라우저로 열면 됩니다.

## 배포 (Railway)
1. [railway.com](https://railway.com)에 GitHub 계정으로 로그인합니다.
2. **New Project → Deploy from GitHub repo**에서 이 저장소를 고릅니다. `package.json`과 `railway.json`을 읽어 `node server.js`로 실행합니다.
3. 서비스의 **Settings → Networking → Generate Domain**을 누르면 `https://○○○.up.railway.app` 주소가 생깁니다.
4. QR 코드는 `https://○○○.up.railway.app/?k=접속키` 주소로 만듭니다.

`main`에 푸시하면 Railway가 자동으로 다시 배포합니다.

## 배포 (GitHub Pages)
저장소 **Settings → Pages → Build and deployment**에서 Source를 `Deploy from a branch`로, 브랜치와 `/ (root)` 폴더를 선택하면
`https://<계정>.github.io/<저장소>/` 주소로 열립니다. 이 주소를 QR로 만들어 오픈채팅방에 공유하세요.

## 파일
